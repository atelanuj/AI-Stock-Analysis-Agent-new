# Stock AI Agent V8.1 Fixes

V8.1 is a polish/fix release focused on usability issues reported after V8.

## Included fixes

- IPO Research tab UI improved for readability and spacing.
- Added IPO search/filter bar for symbol and company name.
- Fixed missing Stocks tab icon by using a universally available icon.
- Improved light-mode readability for primary blue buttons.
- Fixed V8 Assistant send button styling and loading state.
- Intraday tab enhanced with a clearer technical plan:
  - BUY / HOLD / SELL action
  - technical target
  - stop-loss / risk-control
  - risk/reward
  - technical confirmation list
  - risks / invalidation list
  - deterministic technical interpretation cards

## Compatibility

- Built on V8.
- Does not remove existing Stocks, Funds, Screener, Portfolio, Watchlist, Market, IPO, or Assistant functionality.
